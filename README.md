# Moon Barbershop

Menu & tarifs website for Moon Barbershop. Static HTML/CSS/JS, no build step, mobile-first.

- `index.html` — the menu (Coupe, Barbe, Soin visage, Soin cheveux, Coloration, Nos packs)
- `style.css` — chalkboard + gold styling, responsive layout
- `script.js` — sticky category chips, scroll reveal, live open/closed badge (Morocco time), image lightbox
- `images/menu.jpg` — the original printed menu

To change a price, edit the matching `<li>` in `index.html`.

Run locally:

```bash
py -m http.server 5173
```
